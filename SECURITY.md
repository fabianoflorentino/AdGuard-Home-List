# Security policy

## Supported versions

This project publishes lists and a static website from the `main` and
`gh-pages` branches. Only the latest state of those branches is supported.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Use GitHub's private vulnerability reporting:

<https://github.com/fabianoflorentino/AdGuard-Home-List/security/advisories/new>

Include:

- a description of the issue;
- steps to reproduce;
- affected files or URLs;
- potential impact.

You can expect an initial response within a few days. Once the issue is
confirmed and fixed, a public advisory may be published with credit.
