01 // QUICKSTART

Plug into AdGuard Home

Copy a URL below and paste it into AdGuard Home. The lists are rebuilt every day at 04:00 UTC and served straight from GitHub Pages.

AllowList

recommended

Whitelist legitimate domains, CDNs, payment providers, streaming and game platforms so normal browsing never breaks.

https://raw.githubusercontent.com/fabianoflorentino/AdGuard-Home-List/gh-pages/AdGuard-Home-List.Allow.txt

BlockList

optional

Ads, trackers, telemetry, phishing and typo-squatting domains, consolidated from trusted community sources.

https://raw.githubusercontent.com/fabianoflorentino/AdGuard-Home-List/gh-pages/AdGuard-Home-List.Block.txt
  1. Open AdGuard Home → Filters → DNS allowlists.
  2. Paste the URL and hit save.
  3. Done — AdGuard Home refreshes the list on its own.
02 // FEATURES

Built for real networks

No accounts, no telemetry, no proprietary magic. Just plain text lists, generated in the open.

Allowlist first

Carefully curated exceptions for services, OS updates, clouds and payment flows.

Refreshed daily

A scheduled workflow rebuilds, cleans and publishes both lists every day at 04:00 UTC.

De-duplicated

Multiple upstream sources are merged into a single normalized AdGuard syntax list.

Open source

TypeScript CLI, public workflows and a static site. Read every line, run your own copy.

Community driven

Rules from well-known projects like AdGuard, StevenBlack, blocklistproject and more.

Portable syntax

Works with AdGuard Home and other tools that support AdGuard filtering rules.

04 // DEPLOY

Fork it. Own it.

Everything is open source. Fork the repository, enable GitHub Pages and you have your own always-updated DNS lists.

  1. Fork this repository on GitHub.
  2. Enable Pages → Source: branch gh-pages / root.
  3. Run the Publish workflow from the Actions tab.
  4. Point AdGuard Home to your own raw URLs.
your-lists.sh 
# fork + clone
git clone https://github.com/<you>/AdGuard-Home-List.git
cd AdGuard-Home-List

# publish on every push to main
git push origin main

# your URLs
https://raw.githubusercontent.com/<you>/AdGuard-Home-List/gh-pages/AdGuard-Home-List.Allow.txt
https://raw.githubusercontent.com/<you>/AdGuard-Home-List/gh-pages/AdGuard-Home-List.Block.txt
